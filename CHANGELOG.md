# Changelog

All notable changes will be documented here. This project uses semantic versioning after its first public release.

## [0.1.0] - 2026-09-22

### Added

- Three disclosed US-equity screens with explicit exclusions and deterministic ranking.
- Stop-risk and portfolio-slot position-sizing methods with separate versioned names.
- Evidence-first research briefs, contrary-evidence handling, and visible coverage gaps.
- Tailwind, headwind, and uncertainty registers with triggers and reassessment actions.
- Stateful, deduplicated monitoring with failure retention and recovery events.
- ATR-based support/resistance zones and conditional entry/invalidation/reassessment plans.
- Strict JSON provider contract and an offline fictional dataset.
- CLI, Markdown reference report, CI, 25 reference tests, and two optional agent skills.
