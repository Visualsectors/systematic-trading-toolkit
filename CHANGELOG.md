# Changelog

All notable changes will be documented here. This project uses semantic versioning after its first public release.

## [Unreleased]

- Added six discoverable top-level tool folders, structured quickstarts, runnable launchers, and a standalone `risk` command.
- Updated the live adapter for API 2.2.0 SEC metrics and per-indicator technicals; withdrawn earnings timing stays null with a visible gap.
- Added graceful optional-evidence failures, uncached full-path login verification, and safe 401 login guidance.
- Fixed all CLI help paths, documented a working source install and served quotas, and added contract/live launch QA checks.
- Added the live Visual Sectors Data API provider, free-key login, live planning, and daily response cache.
- Added saved-plan monitoring events for entry, reassessment, and invalidation crossings.
- Added historical level base rates, reward-to-reassessment R, and ATR stop distance to plans.
- Enforced decision-time cutoffs, stable risk IDs, strict evidence, bounded sizing, and Windows JSON encodings.
- Changed code licensing to MIT and documentation licensing to CC BY 4.0.

## [0.1.0] - 2026-09-22

### Added

- Three disclosed US-equity screens with explicit exclusions and deterministic ranking.
- Stop-risk and portfolio-slot position-sizing methods with separate versioned names.
- Evidence-first research briefs, contrary-evidence handling, and visible coverage gaps.
- Tailwind, headwind, and uncertainty registers with triggers and reassessment actions.
- Stateful, deduplicated monitoring with failure retention and recovery events.
- ATR-based support/resistance zones and conditional entry/invalidation/reassessment plans.
- Strict JSON provider contract and an offline fictional dataset.
- CLI, Markdown reference report, CI, 25 reference tests, and two optional agent skills.
